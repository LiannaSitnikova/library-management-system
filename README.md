# Система Управління Бібліотекою (Library Management System)

Навчальний проєкт на TypeScript для управління каталогом книг та читачами.

## Функціонал
- Додавання, редагування та вилучення книг і читачів.
- Видача книг читачам та контроль повернення.
- Автоматичні юніт-тести (Mocha/Chai).
- Перевірка якості коду (ESLint v9, Prettier, Husky pre-commit hooks).

## Технологічний стек
- **Мова:** TypeScript
- **Збірник (поточний):** Vite
- **Збірник (legacy):** Webpack
- **Тестування:** Mocha, Chai, tsx
- **Якість коду:** ESLint v9, Prettier, Husky
